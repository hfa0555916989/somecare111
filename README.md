# موقعك على Vercel مع لوحة تحكم

## 1) الرفع على Vercel
**الطريقة أ (الأسهل): GitHub**
1. أنشئ مستودعاً جديداً على GitHub وارفع فيه محتويات هذا المجلد (بعد فك الضغط).
2. في Vercel اضغط Add New ← Project ← اختر المستودع ← Deploy.

**الطريقة ب: من الجهاز**
```
npm i -g vercel
cd المجلد
vercel --prod
```

## 2) كلمة مرور لوحة التحكم
Vercel ← مشروعك ← Settings ← Environment Variables، أضف:
- `ADMIN_PASSWORD` = كلمة مرور قوية
- `AUTH_SECRET` = أي نص عشوائي طويل

## 3) ربط قاعدة البيانات (لحفظ الأسعار والنصوص)
Vercel ← مشروعك ← Storage ← Create Database ← **Upstash Redis** (الخطة المجانية تكفي) ← Connect to Project.
المتغيرات تُضاف تلقائياً (KV_REST_API_URL و KV_REST_API_TOKEN).

## 4) ربط مخزن الصور والفيديو
Storage ← Create ← **Blob** ← Connect to Project. يُضاف `BLOB_READ_WRITE_TOKEN` تلقائياً.

## 5) أعد النشر
Deployments ← آخر نشر ← ⋯ ← Redeploy.

## 6) استخدام لوحة التحكم
افتح `https://موقعك.vercel.app/admin` وسجّل الدخول.
من هناك تعدّل: الشعار والهوية، الواجهة، الباقات والأسعار، الإضافات، المميزات، الصور والفيديو، رقم واتساب، الألوان، وSEO. اضغط «حفظ التغييرات» وتظهر فوراً على الموقع.

## ملاحظات
- الصور الافتراضية موجودة في `public/images` ويمكنك استبدالها من اللوحة برفع صور جديدة.
- رقم واتساب يُكتب بالصيغة الدولية بدون + (مثال 966530779934).
- قبل ربط قاعدة البيانات يعمل الموقع بالمحتوى الافتراضي، لكن الحفظ من اللوحة لن يعمل.
